# Reference Atlas

This is a reference obsidian vault for topics that a PhD in quantum engineering, especially experimental trapped ion quantum computing, should know.

**It was built primarily by the help of Claude Fable 5 in July 2026**

It wins over Wikipedia because it is more concise and pointed in the direction of quantum computing.

The main usecase is for when you are reading papers, and you forget a concept, you can quickly find it in the vault, spend ~2 minutes reading the page, then continue reading what you initially wanted to.

The secondary benefit is that it provides a beautiful visualization of the concepts.

To use it, install [Obsidian](https://obsidian.md/) and just open the root directory (this directory) using it, for free.
